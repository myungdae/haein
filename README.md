# 강해인 시낭송 효 콘서트 홈페이지

시인·시낭송가 강해인의 공식 홈페이지

🌐 **도메인**: [kanghaein.com](https://kanghaein.com)

## 페이지 구성

| 페이지 | 파일 | 설명 |
|--------|------|------|
| HOME | `index.html` | 메인 페이지, Hero, 대표 공연, 창작시, 공연 소식 |
| 강해인 | `pages/about.html` | 프로필, 약력, 수상, 언론 보도 |
| 창작시 | `pages/poems.html` | 창작시 목록 (검색/모달) |
| 효 콘서트 | `pages/concert.html` | 공연 아카이브 (필터) |
| 갤러리 | `pages/gallery.html` | Masonry Grid + Lightbox |
| 시낭송교실 | `pages/class.html` | 수업 소개, 커리큘럼, 일정, 신청 |
| 공연문의 | `pages/contact.html` | 문의 폼, SNS, 지도 |

## 기술 스택

- 순수 HTML5 + CSS3 + Vanilla JavaScript
- Google Fonts (Noto Serif KR, Noto Sans KR, Playfair Display)
- GitHub Pages 정적 호스팅

## 색상 팔레트

- **Ivory** `#FDFAF5` — 배경 기본색
- **Warm Beige** `#F5EDD8` — 섹션 배경
- **Soft Gold** `#C9A96E` — 포인트 컬러
- **Deep Brown** `#3E2723` — 주요 텍스트 / 헤더 배경

## 이미지 교체 안내

`images/` 폴더에 아래 이미지를 추가하면 자동 적용됩니다:

- `hero-bg.jpg` — 메인 Hero 배경 (무대 사진 권장, 1920×1080 이상)
- `og-image.jpg` — SNS 공유 썸네일 (1200×630)
- 갤러리 이미지는 `images/gallery/` 폴더에 추가
